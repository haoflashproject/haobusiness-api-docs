HAObusiness

HAObusiness API

Introduction

HAObusiness API memungkinkan mitra bisnis untuk menyediakan berbagai produk digital kepada pelanggan, seperti pulsa, paket data, pembayaran tagihan (PPOB), saldo uang elektronik (e-wallet), dan layanan digital lainnya melalui integrasi API.

API Endpoint

Environment Base URL
Staging https://haobusiness.id/partner/dev

Mitra dapat menggunakan API berikut untuk mengintegrasikan sistem mitra dengan layanan produk digital HAO Business, sesuai dengan fungsi masing-masing endpoint yang dijelaskan pada tabel berikut.

Endpoint Description Path Method
Product List Get list of available digital products /getproduct GET
Topup Sent topup payment request /topup POST
Inquery Get a bill detail for a specific Customer ID /inquery POST
Payment Sent payment request after inquery /payment POST
Balance Get account balance information /balance GET
Check Status Get final transaction status /checkstatus GET

Services

Berikut adalah layanan yang tersedia melalui HAObusiness API:

Product List

Product List merupakan layanan untuk mendapatkan daftar produk digital yang tersedia.

Topup

Topup merupakan jenis transaksi yang tidak wajib melalui proses inquery. Jenis transaksi ini digunakan untuk melakukan transaksi produk digital prabayar seperti pulsa, paket data, dan direct PLN token.

Inquery

Inquery merupakan layanan yang digunakan untuk memperoleh rincian tagihan produk PPOB berdasarkan ID pelanggan atau nomor akun tertentu sebelum melakukan pembayaran.

Payment

Payment merupakan jenis transaksi yang wajib melalui proses inquery terlebih dahulu sebelum permintaan pembayaran dilakukan. Jenis transaksi ini digunakan untuk membayar tagihan produk PPOB.

Balance

Balance merupakan layanan yang digunakan untuk memeriksa saldo akun mitra.

Callback

Jika request menyertakan parameter url_callback sistem akan mengirimkan final status transaksi ke URL tersebut ketika transaksi berhasil atau gagal. Mitra harus menyediakan endpoint url_callback untuk menerima callback tersebut.

  • Parameter url_callback hanya tersedia untuk endpoint topup dan payment.
  • Gunakan endpoint Check Status sebagai alternatif untuk mendapatkan final status transaksi apabila callback tidak diterima.

Contoh format callback:

  • https://{ip-or-domain}/...
  • http://{ip-or-domain}/...

Cara penggunaan callback:

  • Untuk menggunakan callback pada endpoint topup bisa lihat pada bagian Request & Response Example Topup #
  • Untuk menggunakan callback pada endpoint payment bisa lihat pada bagian Request & Response Example Payment #

Check Status

Check Status merupakan layanan yang digunakan untuk memeriksa final status transaksi pada endpoint path Topup dan Payment (tidak termasuk inquery) apabila callback tidak diterima atau transaksi masih berstatus pending.

HTTP Request Format

Content Type

Semua request harus menggunakan format application/json pada header Content-Type.

HTTP Header

Key Value Type
Content-Type application/json String
signature Signature String
timestamp date-time ISO 8601 String
  • Untuk mendapatkan nilai signature bisa lihat pada bagian Signature #
  • Untuk mendapatkan nilai timestamp bisa lihat pada bagian Timestamp #

Payload Sign

Payload Sign diperlukan sebagai salah satu key dalam pembuatan Canonical Request.

payloadSign = partner_id + reff_id + product + customer_id + req_price
Key Description Required Type
partner_id Provided by HAObusiness Yes String
reff_id Partner Reference ID Yes String (max 15)
product Product Code Yes String
customer_id Customer ID/Phone Number Yes String
req_price Request Price Yes Number

Contoh:

partner_id = 'PARTNER1'
reff_id = '12345'
product = 'S5'
customer_id = '081212312368'
req_price = 0

Buat payloadSign:

payloadSign = PARTNER112345S50812123123680

Canonical Request

Canonical Request diperlukan sebagai salah satu key dalam pembuatan Signature. Canonical Request didapatkan dengan menggabungkan method, path, payloadSign, dan timestamp menggunakan tanda titik dua (:) sebagai pemisah.

canonicalRequest = method:path:payloadSign:timestamp
Key Description Required Type
method HTTP Method Used Yes String
path Endpoint path Yes String
payloadSign Signature Payload Yes String
timestamp date-time ISO 8601 Yes String

Contoh:

method = 'POST'
path = 'topup'
payloadSign = PARTNER112345S50812123123680
timestamp = 1792612847

Buat canonicalRequest:

canonicalRequest = POST:topup:PARTNER112345S50812123123680:1792612847

Signature

Signature dihasilkan menggunakan algoritma HMAC-SHA256 dengan memasukkan nilai canonicalRequest dan secret kemudian dikonversi ke format Hex.

signature = HmacSha256(canonicalRequest, secret)
Component Value Description
Algorithm HMAC SHA256 Signature Algorithm Used
canonicalRequest Canonical Request String The request data concatenated in a predefined order to generate the signature.
secret Provided by HAObusiness The secret key you received from HAObusiness during partner onboarding

Contoh generate signature menggunakan algoritma HMAC SHA256 dengan encoding Hex:

Golang

func CreateHMAC(canonicalRequest []byte, secret string) string {
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write(canonicalRequest)
	return hex.EncodeToString(mac.Sum(nil))
}

JavaScript

const crypto = require("crypto");

function CreateHMAC(canonicalRequest, secret) {
  return crypto
    .createHmac("sha256", secret)
    .update(canonicalRequest)
    .digest("hex");
}

PHP

function CreateHMAC(string $canonicalRequest, string $secret) {
    return hash_hmac('sha256', $canonicalRequest, $secret);
}

Buat signature:

signature = db1ea3195005e7d32bb594cf887c680c0d5fe0c97ab9ea650e876894bd28d734

Timestamp

Nilai Timestamp menggunakan Unix timestamp dalam satuan detik. Timestamp digunakan untuk menentukan masa berlaku transaksi selama 5 menit apabila transaksi belum pernah diterima atau diproses sebelumnya.

Nilai timestamp diabaikan apabila transaksi dengan payload dan timestamp yang sama telah diterima sebelumnya.

Contoh nilai Timestamp:

1792612847

Topup

Endpoint Path

POST {base_url}/topup

Request

Key Value Type
payloadSign partner_id + reff_id + product + customer_id + req_price String 
payloadSign = partner_id + reff_id + product + customer_id + req_price
  • Parameter req_price digunakan untuk mengunci harga transaksi. Sistem akan membandingkan nilai req_price dengan harga pada sistem biller. Jika nilainya berbeda, transaksi akan ditolak.
  • Gunakan nilai 0 pada req_price untuk memproses transaksi tanpa validasi harga.

method = 'POST'
path = 'topup'
partner_id = 'PARTNER1'
reff_id = '123456722'
product = 'S5'
customer_id = '081230000001'
url_callback: 'https://example.com'
req_price = 0
