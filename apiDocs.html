HAObusiness API

Introduction

HAObusiness API memungkinkan mitra bisnis untuk menyediakan berbagai produk digital kepada pelanggan, seperti pulsa, paket data, pembayaran tagihan (PPOB), saldo uang elektronik (e-wallet), dan layanan digital lainnya melalui integrasi API.

API Endpoint

Environment Base URL
Staging https://haobusiness.id/partner/dev

Mitra dapat menggunakan API berikut untuk mengintegrasikan sistem mitra dengan layanan produk digital HAO Business, sesuai dengan fungsi masing-masing endpoint yang dijelaskan pada tabel berikut.

Endpoint Description Path Method
Produk List Mendapatkan daftar produk digital yang tersedia /getproduct GET
Inquery Memeriksa tagihan PPOB sebelum pembayaran /inquery POST
Topup Melakukan transaksi produk digital prabayar /topup POST
Payment Membayar tagihan PPOB setelah inquery /payment POST
Balance Memeriksa saldo akun mitra /balance GET
Check Status Memeriksa status akhir transaksi /checkstatus GET

Services

Berikut adalah layanan yang tersedia melalui HAObusiness API:

Produk List

Path /getproduct digunakan untuk mendapatkan daftar produk digital yang tersedia.

Inquery

Path /inquery digunakan untuk memperoleh informasi tagihan produk PPOB sebelum transaksi payment dilakukan.

Topup

Path /topup digunakan untuk transaksi produk selain payment PPOB, seperti pulsa, paket data, dan direct pln token (tanpa inquery).

Request Parameter

Untuk path /topup, dapat memerhatikan beberapa hal berikut:

PayloadSign = partner_id + reff_id + product + customer_id + req_price
  • Parameter req_price digunakan untuk mengunci harga transaksi. Sistem akan membandingkan nilai req_price dengan harga pada sistem biller. Jika nilainya berbeda, transaksi akan ditolak.
  • Gunakan nilai 0 pada req_price untuk memproses transaksi tanpa validasi harga.

Payment

Path /payment digunakan untuk melakukan pembayaran produk PPOB setelah proses inquery berhasil dilakukan.

Balance

Path /balance digunakan untuk memeriksa saldo akun mitra.

Check Status

Path /checkstatus digunakan untuk memperoleh final status transaksi apabila callback tidak diterima atau transaksi masih berstatus pending.

Callback

Jika request menyertakan parameter url_callback sistem akan mengirimkan final status transaksi ke URL tersebut ketika transaksi berhasil atau gagal. Mitra harus menyediakan endpoint url_callback untuk menerima callback tersebut.

  • Parameter url_callback hanya tersedia untuk endpoint topup dan payment.
  • Gunakan endpoint checkstatus sebagai alternatif untuk mendapatkan final status transaksi apabila callback tidak diterima.

Contoh format callback:

  • [POST] https://{ip-or-domain}/...
  • [POST] http://{ip-or-domain}/...

HTTP Request Format

Content Type

Semua request harus menggunakan format application/json pada header Content-Type.

HTTP Header

Setiap request harus menyertakan header berikut:

Key Value Type
Content-Type application/json String
signature Signature String
timestamp Timestamp Number
  • Untuk mendapatkan nilai signature bisa lihat pada bagian Signature #
  • Untuk mendapatkan nilai timestamp bisa lihat pada bagian Timestamp #

Payload Sign

Payload Sign diperlukan sebagai salah satu key dalam pembuatan Canonical Request. Payload Sign didapatkan dengan menggabungkan nilai partner_id, reff_id, product, customer_id, dan req_price secara berurutan tanpa pemisah.

payloadSign = partner_id + reff_id + product + customer_id + req_price
Key Description Required Type
partner_id Partner ID yang diberikan oleh HAObusiness Yes String
reff_id ID referensi transaksi Yes String (max 15)
product Produk yang dibeli Yes String
customer_id Nomor pelanggan Yes String
req_price Harga permintaan Yes String

Contoh:

partner_id = 'PARTNER1'
reff_id = '12345'
product = 'S5'
customer_id = '081212312368'
req_price = '0'

Contoh hasil:

payloadSign = PARTNER112345S50812123123680

Canonical Request

Canonical Request diperlukan sebagai salah satu key dalam pembuatan Signature. Canonical Request didapatkan dengan menggabungkan method, path, payloadSign, dan timestamp menggunakan tanda titik dua (:) sebagai pemisah.

canonicalRequest = method:path:payloadSign:timestamp
Key Description Required Type
method Metode HTTP yang digunakan Yes String
path Path endpoint Yes String
payloadSign Signature Payload Yes String
timestamp Timestamp transaksi Yes String

Contoh:

method = 'POST'
path = 'topup'
payloadSign = PARTNER112345S50812123123680
timestamp = 1792612847

Contoh hasil:

canonicalRequest = POST:topup:PARTNER112345S50812123123680:1792612847

Signature

Signature dihasilkan menggunakan algoritma HMAC-SHA256 dengan secret sebagai kunci dan canonicalRequest sebagai data input. Hasil perhitungan kemudian dikonversi ke format Hex.

signature = HmacSha256(canonicalRequest, secret)
Component Value Description
Algorithm HMAC SHA256 Jenis algoritma signature yang digunakan
canonicalRequest Canonical Request String Request yang telah diubah menjadi format canonical
Secret Diberikan oleh HAObusiness Secret untuk pembuatan signature

Contoh generate signature menggunakan algoritma HMAC SHA256 dengan encoding Hex:

Golang

func CreateHMAC(canonicalRequest []byte, secret string) string {
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write(canonicalRequest)
	return hex.EncodeToString(mac.Sum(nil))
}

JavaScript

const crypto = require("crypto");

function CreateHMAC(canonicalRequest, secret) {
  return crypto
    .createHmac("sha256", secret)
    .update(canonicalRequest)
    .digest("hex");
}

PHP

function CreateHMAC(string $canonicalRequest, string $secret) {
    return hash_hmac('sha256', $canonicalRequest, $secret);
}

Contoh hasil:

signature = db1ea3195005e7d32bb594cf887c680c0d5fe0c97ab9ea650e876894bd28d734

Timestamp

Nilai Timestamp menggunakan Unix timestamp dalam satuan detik. Timestamp digunakan sebagai batas waktu transaksi selama 5 menit apabila transaksi belum pernah diterima atau diproses sebelumnya.

Transaksi tidak dianggap expire berdasarkan timestamp apabila transaksi tersebut sudah pernah diterima dan dikirim ulang menggunakan payload serta timestamp yang sama.

Contoh nilai Timestamp:

1792612847
