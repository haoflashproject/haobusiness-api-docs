Authentication

API Keys

API key adalah identitas unik yang digunakan untuk mengautentikasi permintaan ke API. Sertakan API key pada setiap permintaan untuk mengidentifikasi aplikasi dan memverifikasi hak akses terhadap sumber daya yang tersedia.

Jaga kerahasiaan API key Anda. Hindari menempatkan key rahasia di kode frontend, repositori publik, atau aplikasi yang dapat diakses langsung oleh pengguna. Simpan kredensial sensitif di server dan segera ganti API key jika diketahui telah bocor.

Bearer Token

Bearer token adalah kredensial akses yang dikirim melalui header Authorization pada permintaan HTTP. API akan memvalidasi token untuk menentukan apakah permintaan telah terautentikasi dan diizinkan mengakses sumber daya yang diminta.

Gunakan skema autentikasi Bearer saat mengirim token. Selalu gunakan HTTPS untuk melindungi kredensial selama transmisi. Hindari mencatat token ke dalam log atau membagikannya kepada pihak yang tidak berwenang. 

Authorization: Bearer TOKEN_AKSES_ANDA

Endpoints

GET /api/v1/products

Mengambil daftar produk.

fetch("/api/v1/products", {
    method: "GET",
    headers: {
        "Authorization": "Bearer YOUR_API_KEY"
    }
})
.then(response => response.json())
.then(data => {
    console.log(data);
});
