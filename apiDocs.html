Header

Setiap request harus menyertakan header berikut:

Key Value
Content-Type application/json
signature Signature
timestamp Timestamp

Nilai Timestamp menggunakan Unix timestamp dalam satuan detik. Timestamp digunakan sebagai batas waktu transaksi selama 5 menit apabila transaksi belum pernah diterima atau diproses sebelumnya.

Transaksi tidak dianggap expire berdasarkan timestamp apabila transaksi tersebut sudah pernah diterima dan dikirim ulang menggunakan payload serta timestamp yang sama.

Contoh nilai Timestamp:

1792612847

Nilai signature dibuat menggunakan metode HmacSha256 dengan encoding Hex.

Proses pembentukan signature:

partner_id = 'PARTNER1'
reff_id = '12345'
product = 'S5'
customer_id = '081212312368'
req_price = '0'
method = 'POST'
path = 'topup'
timestamp = 1792612847

payloadSign = partner_id + reff_id + product + customer_id + req_price
canonicalRequest = method:path:payloadSign:timestamp
signature = HmacSha256(canonicalRequest, secret)

Contoh hasil:

payloadSign = PARTNER112345S50812123123680
canonicalRequest = POST:topup:PARTNER112345S50812123123680:1792612847
signature = db1ea3195005e7d32bb594cf887c680c0d5fe0c97ab9ea650e876894bd28d734

Callback

Jika request menyertakan parameter url_callback sistem akan mengirimkan final status transaksi ke URL tersebut ketika transaksi berhasil atau gagal.

Parameter url_callback hanya tersedia untuk endpoint topup dan payment. Gunakan endpoint checkstatus sebagai alternatif untuk mendapatkan final status transaksi apabila callback tidak diterima.

Topup

Endpoint topup digunakan untuk transaksi produk selain payment PPOB, seperti pulsa, paket data, dan direct pln token (tanpa inquery).

Inquery

Endpoint inquery digunakan untuk memperoleh informasi tagihan produk PPOB sebelum transaksi payment dilakukan.

Payment

Endpoint payment digunakan untuk melakukan pembayaran produk PPOB setelah proses inquery berhasil dilakukan.

Check Status

Endpoint checkstatus digunakan untuk memperoleh final status transaksi apabila callback tidak diterima atau transaksi masih berstatus pending.

Topup

Untuk endpoint topup, nilai PayloadSign dibentuk menggunakan formula berikut:

PayloadSign = partner_id + reff_id + product + customer_id + req_price

Parameter req_price digunakan untuk mengunci harga transaksi. Sistem akan membandingkan nilai req_price dengan harga pada sistem biller. Jika nilainya berbeda, transaksi akan ditolak.

Gunakan nilai 0 pada req_price untuk memproses transaksi tanpa validasi harga.
